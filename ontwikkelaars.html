Eén API voor al je gesprekken. Gewoon REST en JSON.

Basis-URLhttps://app.botlu.ai/api/v1
InloggenAuthorization: Bearer btl_…
  • GET/callsGesprekken, nieuwste eerst. Met limit (tot 100), before en outcome.
  • GET/calls/{id}Eén gesprek, met het hele transcript.
  • GET/calls/{id}/recordingDe opname als WAV-bestand.
  • GET/agentsJe assistenten: naam, stem, taal en begroeting.
  • GET/numbersJe telefoonnummers en welke assistent opneemt.

Controleer elke webhook. Dan weet je zeker dat hij van ons komt.

webhook-id
Uniek per bericht. Heb je hem al gezien, sla hem dan over.
webhook-timestamp
Wanneer we hem verstuurden, in Unix-tijd. Weiger berichten ouder dan vijf minuten.
webhook-signature
v1, met een HMAC-SHA256 over id, tijd en body, gemaakt met je whsec_-geheim.

Liever niets zelf schrijven? De bibliotheken van Standard Webhooks voor onder meer Node, Python, PHP en Go werken direct.

import crypto from 'node:crypto';

// Het geheim uit je dashboard (whsec_…), zonder het voorvoegsel
const key = Buffer.from(process.env.BOTLU_SECRET.slice(6), 'base64');

// body = de ruwe tekst van het verzoek, niet de geparste JSON
export function echtVanBotlu(headers, body) {
  const id = headers['webhook-id'], ts = headers['webhook-timestamp'];
  if (Math.abs(Date.now() / 1000 - ts) > 300) return false;
  const mac = crypto.createHmac('sha256', key)
    .update(`${id}.${ts}.${body}`).digest('base64');
  const verwacht = Buffer.from(`v1,${mac}`);
  return headers['webhook-signature'].split(' ').some(s => {
    const b = Buffer.from(s);
    return b.length === verwacht.length && crypto.timingSafeEqual(b, verwacht);
  });
}

Sleutels als hash

We bewaren je API-sleutel niet zelf. Kwijt? Maak een nieuwe en trek de oude in.

Elk bericht ondertekend

HMAC-SHA256 volgens Standard Webhooks, met een eigen geheim per webhook.

Alleen https naar buiten

Webhooks gaan alleen naar openbare https-adressen, nooit naar interne netwerken.

Snel of niet

We wachten hooguit acht seconden op je server en volgen geen doorverwijzingen.
